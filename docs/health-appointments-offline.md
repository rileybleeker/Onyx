# Health and recurring appointments: offline stage (superseded)

The first version of `/health` (PR #30, 2026-11-11) kept items in the browser only. Since 2026-11-13 items are stored in Onyx; the current description is in [health-appointments.md](health-appointments.md).

What remains of the offline stage: a browser that still holds items saved by that version is offered one button to copy them into Onyx, after which the page offers to remove the browser copy.
